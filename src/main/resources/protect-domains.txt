# 保护域名（业务优先白名单）
#
# 作用：合并阶段，凡是指向以下域名（含其所有子域）的“拦截规则”一律丢弃；
#       同时把这些域名以 @@ 例外（allowlist）的形式写进 all.txt / dns.txt 末尾，
#       这样即使客户端另外还开了 AdGuard DNS filter 等过滤器，也不会把核心业务挡掉。
#
# 收录标准：只收「拦了会坏功能」的域，不收任何以埋点/日志/广告为主的域。
#   例：snssdk.com 下 29 条被核心源拦截的规则全是 log/mon/applog/mssdk 埋点子域，
#       而 i.snssdk.com、aweme.snssdk.com、ecom.snssdk.com 这些真正的业务接口本来就没被拦，
#       所以 snssdk.com 这种根域不再整体保护——埋点照拦，业务不受影响。
#   例：vivo 的 *-stsdk.vivo.com.cn（onrt/ort/bronrt/appstoreonrt…）全是 SDK 上报，直接放行拦截。
#   例：h-adashx.ut.taobao.com 是淘宝 UT 广告埋点，属于该拦的，不保护。
#
# 写法：一行一个域名，不带 || ^ 等符号；写 douyin.com 即保护 douyin.com 及其全部子域。
# 以 # 开头为注释。改完提交，下一次 CI 编译即生效。
